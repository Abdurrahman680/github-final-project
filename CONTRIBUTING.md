# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for taking the time to contribute!

## How to Contribute

### 1. How to Fork
Click the **Fork** button at the top-right corner of the GitHub repository page to create a personal copy under your GitHub account.

### 2. How to Clone
Clone your forked repository to your local machine:
```bash
git clone https://github.com/Abdurrahman680/simple-interest-calculator.git
cd simple-interest-calculator
```

### 3. How to Create a Branch
Create a new branch for your feature or bug fix:
```bash
git checkout -b feature/your-feature-name
```

### 4. How to Make Changes
Implement your changes in the codebase. Follow good coding practices and keep changes focused and well-documented.

### 5. How to Test
Test your changes locally before committing:
```bash
chmod +x simple-interest.sh
./simple-interest.sh
```
Verify that the output calculations match expected mathematical results.

### 6. How to Submit a Pull Request
1. Commit your changes with a clear message:
   ```bash
   git add .
   git commit -m "feat: description of your changes"
   ```
2. Push your branch to GitHub:
   ```bash
   git push origin feature/your-feature-name
   ```
3. Navigate to the original repository on GitHub and click **Compare & pull request** to submit your Pull Request.

## Reporting Bugs

If you find a bug or issue, please submit an issue detailing:
- The expected behavior
- The actual behavior
- Steps to reproduce
